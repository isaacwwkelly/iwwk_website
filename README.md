# Isaac Kelly (IWWK) - Personal Website

Personal portfolio website for Isaac W.W. Kelly, Full-Stack Software Engineer II.

Live site: [isaacwwkelly.dev](https://isaacwwkelly.dev)

## Tech Stack

- **Framework**: Next.js 15 (App Router with Turbopack), React 19
- **Styling**: Tailwind CSS v4, Custom CSS variable tokens for Light/Dark mode
- **Animations**: Framer Motion
- **UI Components**: Radix UI
- **Forms**: React Hook Form + Web3Forms
- **Hosting**: Vercel

## Local Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
